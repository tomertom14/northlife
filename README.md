# NorthLife

NorthLife is a Hebrew, RTL platform for discovering events and activities in northern Israel.

Project documents:

- [Initial requirements](NorthLife_Initial_Project_Requirements.md)
- [Base implementation plan](NorthLife_Base_Plan.md)

Implementation is organized into independent, testable phases. Phase 0 establishes planning and repository foundations. Later phases add the runnable stack, domain model, public browsing, authentication, event management, moderation, maps, and deployment.

## Status

Planning and repository initialization.
