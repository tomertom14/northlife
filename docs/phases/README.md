# Phase Verification Records

Create one Markdown file per implementation phase. A phase record must contain:

1. Goal and prerequisites.
2. Files and components changed.
3. Implemented behavior and API changes.
4. Fixture setup and exact verification commands.
5. Acceptance checklist with recorded results.

Do not mark a phase complete until its checks and all prerequisite regression checks pass without later-phase code.
